#  Global Cereal Yield Dashboard

This project is a data visualization dashboard built using Streamlit to analyze global cereal yield trends.

#  Features
- Country selection filter
- Year range filter
- Yield trend visualization
- Global average comparison
- Top 10 countries analysis

#  Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

#  How to Run the Project

1. Install required libraries:
pip install streamlit pandas plotly openpyxl

2. Run the application:
python -m streamlit run app.py

#  Files Included
- app.py (main application)
- cereal_yield.xlsx (dataset)

#  Dataset Source
World Bank:
https://data.worldbank.org/indicator/AG.YLD.CREL.KG
